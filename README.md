# Welcome to your Lovable project

## Gestión hotelera Maremoto

El sistema conserva la arquitectura original y amplía reservas, huéspedes,
habitaciones, pagos, servicios y calendario sobre Supabase.

- [Instalación y migración](INTEGRACION.md)
- [Análisis inicial](docs/ANALISIS.md)
- [Cambios, validaciones y pendientes](docs/ENTREGA.md)

**Una base ya instalada necesita la migración `07_gestion_hotelera.sql` antes de
usar los paneles nuevos.** No se aplicaron cambios a Supabase remoto.

This project was built with [Lovable](https://lovable.dev).

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
